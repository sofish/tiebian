# 便签板与编辑器交互

## 行为边界

- 每个 group 一列，标签位于该组第一张便签上方，并与便签左边对齐。短组连同标签在公共列高中垂直居中。无标签的散页也遵循相同布局。
- 顶部标签及其与纸张的间距先计入高度预算，再压缩便签步长。分页继续按列进行，右侧贴边时保留列顺序镜像。
- 点击卡片打开编辑器；收起、「…」、提醒、弹出菜单、分页和撤销都必须能直接点击。
- 只有编辑纸顶部胶带区域接收窗口拖动。`WindowDragHandleView` 处理 AppKit 原生 `mouseDown` / `mouseDragged` / `mouseUp`，以屏幕坐标计算位移；松手后由控制器将窗口限制在当前屏幕可见区域。[Apple 文档](https://developer.apple.com/documentation/appkit/nswindow/performdrag(with:))说明 `performDrag(with:)` 立即返回，也不保证派发 mouse-up，因此不把其返回当作拖动完成信号。
- 拖动距离、速度和是否出屏都不能触发删除。
- 删除入口为编辑器「…」→「删除便签」。删除后显示 6 秒撤销提示，恢复同一 UUID、正文、颜色、置顶、到期与创建/更新时间；空白或只有标签的便签主动删除时也可撤销。删除和恢复后立即保存，避免文件监听在延迟保存前读回旧数据。新建空白便签直接收起仍会自动丢弃。
- 边缘光条在其他 App 前台时也应首次 hover 就展开，展开使用非激活面板，不改变前台 App。全局 `.mouseMoved` 监听负责后台事件，`.activeAlways` tracking area、100ms 轮询和 App Nap activity 兜底；关闭时必须清理监听。
- 菜单栏「光条大小」滑块实时调节并持久化长度：最小 220pt、默认 440pt、最大为当前可用边长的 80%。竖向按高度、横向按宽度，换边或换屏重算范围；小屏只缩短实际显示，不覆盖原有偏好。光条厚度和拖拽换边行为不变。

## 回归验证

运行 `swift test`。`EdgePeekTests` 覆盖四个贴边方向的顶部标签、短组居中、拥挤分页、右侧列镜像、连续快速拖动、胶带命中范围、编辑器删除和撤销后重载文件、未激活时 hover 展开/离开收起、下拉菜单状态、滑块回调及 MCP 配置转义；`EdgePeekCoreTests` 覆盖完整便签恢复、尺寸边界和偏好持久化。

本机 UI 验收必须使用独立数据，避免修改日常便签：

```bash
swift build
EDGEPEEK_DATA_FILE=/tmp/edgepeek-interactions/notes.json \
EDGEPEEK_EDITOR=1 EDGEPEEK_HOLD=1 .build/debug/EdgePeek
```

1. 点击「收起」，确认编辑器关闭；再次打开，点击提醒，设置并清除时间。
2. 点击「…」，切换置顶，确认状态变化；编辑正文，确认正常选字、输入、自动保存。
3. 拖动胶带到新位置并快速甩动，确认只移动，便签数量不变；拖向屏幕边缘后松手，确认纸张回到可见范围。
4. 主动删除，点击撤销，确认相同便签及内容、置顶、提醒恢复。
5. 使用 `EDGEPEEK_DEMO=1 EDGEPEEK_HOLD=1` 展开板子，检查标签在各组顶部、长短组和散页、分页，以及左/右/上/下四边。
6. 正常启动独立数据版本（去掉 `EDGEPEEK_HOLD` / `EDGEPEEK_DEMO`），让其他 App 前台，直接移入光条，确认无需点击就展开且不抢焦点；移开后收起。
7. 在菜单栏拖动光条大小滑块，确认最小、默认、最大、重启恢复和换边约束；检查登录项待批准状态和 helper 缺失提示。自动化测试不注册或取消本机真实登录项。

旧版使用 App 全局鼠标监听移动窗口，未发生拖动时也吞掉 `leftMouseUp`，使按钮收不到完整点击。不要把胶带拖动重新实现为全局鼠标事件拦截。
