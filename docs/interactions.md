# 便签板与编辑器交互

## 行为边界

- 板的方向跟随所贴的边。左/右缝上，每组是一行：标签在上方，便签沿横向铺开；贴左边时整行左对齐，贴右边时整行右对齐，组与组自上而下排列。上/下缝上，每组是一列：标签仍然在上方，便签沿竖向铺开；贴上边时顶对齐，贴下边时底对齐，组与组自左向右排列。短组不再在自己的轨道里垂直居中。
- 便签卡片不区分标题和正文：整段内容用同一种字号按纸张宽度折行，字号保持四行正文完整可读，尽量铺满卡片高度，放不下才在卡片内省略。菜单栏「便签字号」提供小字 / 标准 / 大字，卡片与 hover 预览同步缩放；大字会少排一行但仍按纸张高度截断。纯 hashtag 行交给组标题，不再占用纸张。hover 预览同样整段显示，顶部留白正好一个行高，只有超出预览高度时才省略尾部；置顶、到期和更新时间移到卡片底部一行。
- 标签及其与纸张的间距先计入尺寸预算，再压缩组内步长。分页沿展开方向进行：竖边按行、横边按列。右缝不镜像组顺序，而是把每一行整体右对齐。无标签的散页也遵循相同布局。
- 点击卡片打开编辑器；单张卡片可使用原生 AppKit dragging session 拖出板子，越过板子边界 24pt 后松手删除。拖动时只有指针已越过可删除距离，跟随指针的卡片快照上才盖一枚较大的红色「放开即删除」印章，同时在卡片上方或下方浮出「松手删除」提示；提示贴着被拖动的纸片移动，靠近屏幕底边时改放到纸片上方，并始终留在屏幕内。指针移到其他 group 的区域上方时，提示改为「松手并入 #tag」，无标签组显示「松手并入 散页」；停在便签原本所在的组时不出提示。回到边界内印章与提示一起消失。板内松手归位；拖到另一个 group 的区域上方松手时，把该便签第一个 hashtag 改成目标组的 tag，目标是无标签散页时去掉 tag 并保留原纸色；有 tag 的组按组色同步（组色取最老一张）；拖回原组或空白处不变。Esc 取消不删除；拖动期间暂停自动收起，拖出不需要抢焦点或辅助功能权限。只影响该 UUID，不删除整个 group。收起、「…」、提醒、弹出菜单、分页和撤销都必须能直接点击。
- 只有编辑纸顶部胶带区域接收窗口拖动。`WindowDragHandleView` 处理 AppKit 原生 `mouseDown` / `mouseDragged` / `mouseUp`，以屏幕坐标计算位移；松手后由控制器将窗口限制在当前屏幕可见区域。[Apple 文档](https://developer.apple.com/documentation/appkit/nswindow/performdrag(with:))说明 `performDrag(with:)` 立即返回，也不保证派发 mouse-up，因此不把其返回当作拖动完成信号。
- 编辑器胶带拖动的距离、速度和是否出屏都不能触发删除；仅便签板卡片支持拖出删除。
- 删除入口为编辑器「…」→「删除便签」或板子卡片拖出松手。删除后显示 6 秒撤销提示，恢复同一 UUID、正文、颜色、置顶、到期与创建/更新时间；已有空白或只有标签的便签主动删除时也可撤销。删除和恢复后立即保存，避免文件监听在延迟保存前读回旧数据。
- 新建便签作为草稿：正文按 `whitespacesAndNewlines` trim 后为空时不写入文件，关闭/退出时丢弃，无删除撤销提示；只有 hashtag 算有内容。非空内容继续自动保存，同一新建会话里再清空则从持久化文件移除；已有便签清空不自动删除。文件监听比较上次已知字节避免自写重载，外部更新保留正在编辑的新草稿并合并其他便签。
- 边缘光条在其他 App 前台时也应首次 hover 就展开，展开使用非激活面板，不改变前台 App。全局 `.mouseMoved` 监听负责后台事件，`.activeAlways` tracking area、100ms 轮询和 App Nap activity 兜底；关闭时必须清理监听。
- 菜单栏「光条大小」两个滑块独立实时调节并持久化长宽，第三个滑块单独调节光条上便签总数数字的字号（6–18pt，默认 8.4pt）。长度最小 220pt、默认 440pt、最大为当前可用边长的 80%；竖向按高度、横向按宽度，换边或换屏重算，小屏只缩短显示、不覆盖偏好。可见宽度最小 2.7pt、默认 5.4pt、最大 16.2pt，亮线随宽度缩放，柔光按宽度比例的平方根平缓放大；四边都让亮线接触物理屏幕边缘，接触面没有空隙。日光弧面的中心位于屏幕边缘外，避免出现悬空小球。透明命中深度至少 24pt，按宽度和数字字号扩充避免数字向内被裁切；光条内常驻显示便签总数，有到期便签时数字变红，否则为白色。光晕使用独立的鼠标穿透子面板，向屏幕内及光条两端扩散，不受光条厚度和长度裁切，也不扩大 hover/点击/拖动范围；子面板随光条移动、换边、改尺寸和隐藏，由 SwiftUI 拆卸时移除。顶部也贴物理屏幕顶边，不再预留菜单栏高度。「恢复默认尺寸（2 倍）」同时恢复长宽，不改数字字号。拖拽光条仍只换边。
- `⌃⌥Space` 全局显示 / 收起全部便签，菜单栏有相同入口；`⌘⇧Space` 继续新建。快捷键展开不抢其他 App 焦点，并保持显示直到再按快捷键、点击光条或打开编辑器；不受鼠标远离自动收起影响。若 App 已在前台，Esc 也可收起。各组都进入板子，屏幕不足继续分页；快捷键不会新建便签，编辑器里的空白新草稿会先丢弃。Carbon 按不同 ID 路由两个快捷键，避免一次触发两个动作。

- 菜单栏「光条动画」提供三种选择并记住偏好：三者使用暖白、金色和琥珀色的柔光：流光为从左向右（竖边从上向下）沿地平线匀速移动的日光点（常态 8.4 秒、到期 5.6 秒）；呼吸像经典苹果待机灯，整条柔光原地缓缓明暗，亮起、落下之间短暂休息，无位移或缩放（6.8 / 4.8 秒）；涟漪为空心的椭圆柔光波环，从中间向两端及屏幕内传播，像水面波纹；两圈相差半周期交错衔接（6 / 4 秒）。默认流光，损坏/未知偏好回退流光。底条外侧轮廓贴边、内侧两端渐细中间变宽。动画使用原生 Core Animation 处理 transform / opacity，无每帧 SwiftUI 重建；hover 只更新外观，不重启动画。到期时加快/增强；数字常驻显示（流光时随日光移动，其他模式居中），有到期便签时转红。动画与长宽偏好独立。

## 回归验证

运行 `swift test`。`EdgePeekTests` 覆盖顶部标签、四边横排/竖排与左右/上下对齐、分页、组间拖放改 tag 与「松手并入」提示、拖出删除距离与跟随卡片的删除提示、越过删除距离后出现的「放开即删除」印章、三档便签字号的卡片与预览缩放、卡片字号与行数布局、预览顶部一行行高留白、光条数字字号、原生胶带拖动、卡片点击/拖出删除/取消/撤销、编辑器空白处理、后台 hover、主动展开保持、Carbon 快捷键路由、长宽滑块、光条总数与过期红色、三种原生动画持续时间/hover 不重启、呼吸首尾连续、空心波环与涟漪半周期交错、渐细路径、四边日光弧面与渐隐边界、各宽度和最大数字字号下的光晕余量、鼠标穿透子面板跟随/拆卸、Skill Prompt 路径转义。`EdgePeekCoreTests` 覆盖草稿不落盘、外部更新合并、主标签改写、完整恢复、卡片统一正文、字号与光条数字偏好、尺寸边界和偏好持久化；CLI 的运行验证见 [Skill 文档](skill.md)。

本机 UI 验收必须使用独立数据，避免修改日常便签：

```bash
swift build
EDGEPEEK_DATA_FILE=/tmp/edgepeek-interactions/notes.json \
EDGEPEEK_EDITOR=1 EDGEPEEK_HOLD=1 .build/debug/EdgePeek
```

1. 点击「收起」，确认编辑器关闭；再次打开，点击提醒，设置并清除时间。
2. 点击「…」，切换置顶，确认状态变化；编辑正文，确认正常选字、输入、自动保存。
3. 拖动胶带到新位置并快速甩动，确认只移动，便签数量不变；拖向屏幕边缘后松手，确认纸张回到可见范围。
4. 主动删除，点击撤销，确认相同便签及内容、置顶、提醒恢复。
5. 使用 `EDGEPEEK_DEMO=1 EDGEPEEK_HOLD=1` 展开板子，检查标签在各组上方、长短路、分页；用 `EDGEPEEK_POSITION` 轮换四边，确认左/右为横排且分别左/右对齐，上/下为竖排且分别顶/底对齐。
6. 正常启动独立数据版本（去掉 `EDGEPEEK_HOLD` / `EDGEPEEK_DEMO`），让其他 App 前台，直接移入光条，确认无需点击就展开且不抢焦点；移开后收起。
7. 在菜单栏分别拖动长宽与数字字号滑块，检查最小、默认、最大、重启恢复、四边贴合及换屏约束；切换「便签字号」三档，确认卡片与 hover 预览同步缩放、卡片始终不溢出纸张。让其他 App 前台，按 `⌃⌥Space`，鼠标远离仍保持展开，再按收起，`⌘⇧Space` 仍只新建。
8. 新建后不输入、只输空白、输入后清空，检查文件中无这条便签；只写 `#标签` 应保留。旧便签清空应保留。Agent 在此时新增其他便签，不应让草稿丢失。
9. hover 展开后拖动单张卡片离开板子，确认板子不提前收起；在板内和 24pt 边界内拖动时快照保持干净，越过边界 24pt 后快照上才出现「放开即删除」印章，同时被拖动卡片的上方或下方出现「松手删除」提示，提示随手移动、贴边时换到另一侧，回到边界内两者一起消失；板内放下/Esc 取消保留，边界外 24pt 松手删除且可撤销，同组其他便签不受影响。把卡片拖到另一组上方时，提示显示「松手并入 #tag」，在该组松手后确认 tag 改成目标组且整组纸色同步；拖回原组、空白处或按 Esc 都不改 tag，原组上方不显示并入提示。检查右键菜单、分页、编辑按钮正常。检查卡片直接显示整段正文（首行不再放大），字号足够大且按纸张高度截断；hover 预览顶部留白正好一个行高，内容尽量完整。
10. 切换流光/呼吸/涟漪，检查变化明显、运动连续、hover 不跳回起点，改长宽和换边后保持形态，重启保留选择；检查后台和到期状态。在深浅两种桌面背景下，确认光核像日光从屏幕边缘探出、外晕超出光条厚度且两端没有矩形截断；仅移入外晕不应展开便签板，拖动及换边后光核仍贴边。
11. 检查登录项待批准状态和 Skill/CLI 缺失提示。自动化测试不注册或取消本机真实登录项。

旧版使用 App 全局鼠标监听移动窗口，未发生拖动时也吞掉 `leftMouseUp`，使按钮收不到完整点击。不要把胶带拖动重新实现为全局鼠标事件拦截。
